# Construction Expense Management System

A professional construction financial tracking and expense management solution designed for construction owners and site managers.

## Key Features
- House-wise expense tracking
- Material and labour management
- Financial dashboard
- Payment tracking
- Excel and PDF reporting
- Responsive modern interface

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- ClosedXML
- QuestPDF
